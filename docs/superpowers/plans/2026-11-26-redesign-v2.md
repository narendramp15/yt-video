# yt-video v2 Redesign — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restructure yt-video into a `yt_video/` package of stages and swappable providers. Every LLM call runs through the Claude Code CLI first and falls back to `gpt-6-luna`. Images come from a free provider chain. Feature parity with Phases A–C is kept.

**Architecture:**
- A `Pipeline` runs 12 `Stage` objects over a `RunContext`. Each stage's output is checkpointed into a per-run folder, `output/runs/<id>/run.json`.
- All outside services sit behind small protocols: `LLMProvider`, `ImageProvider`, plus TTS and transcribe functions. Tests swap in fakes.
- Durable learned state lives in `state/`.
- The old `services/` and `workflows/` code keeps working until the final task deletes it.

**Tech Stack:**
- Python 3.11 under `uv`
- pydantic v2 + pydantic-settings
- `claude` CLI 2.1.332 run via `subprocess`
- `openai` SDK, requests (Pollinations, Cloudflare)
- edge-tts, faster-whisper, MoviePy/FFmpeg, google-api-python-client
- sqlite3, pytest

**Spec:** `docs/superpowers/specs/2026-11-26-redesign-v2-design.md`. Read it before any task. Section refs below (§) point there.

## Global Constraints

- Run every Python tool through uv: `uv run pytest`, `uv run python ...`. Never call bare `python` or `pip`.
- Windows 11. Paths go through `pathlib.Path`. Every file and subprocess I/O passes `encoding="utf-8"` explicitly, because the Windows default codepage is cp1252.
- Never pass `--bare` to `claude`. It disables subscription OAuth.
- Default LLM order is `claude_cli,openai`. OpenAI model is `gpt-6-luna` at $0.10 input / $0.50 output per 1M tokens.
- Default Claude models: `sonnet` for the `script` tier, `haiku` for the `light` tier.
- Default image order is `pollinations,cloudflare,placeholder`. Providers without credentials are skipped. OpenAI images are never in the default chain.
- The circuit breaker trips on the **first** usage-limit, rate-limit or overage signal from Claude. After it trips, Claude is skipped for the rest of the run.
- Claude CLI calls are recorded at `cost_usd = 0.0`. The envelope's cost goes into `notional_cost_usd`.
- When privacy is in doubt it is `private`. Public requires `score >= 80` **and** `safety == "Yes"`. A missing safety value counts as `"No"`.
- No module under `yt_video/` imports `moviepy`, `torch`, `transformers`, `faster_whisper` or `edge_tts` at module level. Import them inside the functions that use them, so `uv run pytest tests` stays under 30 s.
- `tests/` never touches the network, the real `claude` binary or real API keys. Real calls go only in `tests/live/`, marked `@pytest.mark.live`.
- Keep existing env var names. New ones are exactly as in §6.5.
- Commit after every task, with messages ending `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Push only when the owner asks.
- Model routing for subagents (owner's CLAUDE.md): Sonnet by default. Haiku is enough for Tasks 13 and 20.

## Decisions this plan adds (implementer: follow these; they refine the spec)

1. **Run folder name.** The folder is `output/runs/<YYYY-MM-DD>_<HHMMSS>/`, not `<date>_<slug>`. The slug is only known after the packaging stage, and renaming a folder mid-run fails on Windows while the log file is open. The slug is stored in `run.json`, and artifacts are named `<slug>.mp4`, `<slug>_shorts.mp4` and so on.
2. **No approval pointer file.** The single-unfinished-run invariant makes `RunStore.latest_unfinished()` the unique target for `--approve/--reject/--list-packaging`. The pending file lives at `<run dir>/packaging_pending.json`.
3. **LLM-facing schemas use lists, not dicts.** Every field is required, so the same JSON Schema works for `claude --json-schema` and OpenAI strict structured outputs. For example, scene prompts are `list[ScenePrompt(label, prompt)]`.
4. **Reddit is not a v1 feature.** No PRAW code exists, even though the README mentions it. It is dropped from parity, and the README is corrected in Task 20.
5. **Dead code is not ported:** `chart_service.py`, `fetch_nifty_movers`, `generate_scene_images_for_movers`, and the `ticker_items`/`stat_cards` render args. `mplfinance` is dropped from deps. `yfinance` stays for news topics.
6. **Prompts use `string.Template` (`$name`) placeholders,** so the JSON braces in prompt examples need no escaping.
7. **Migration is a flag, `--migrate-state`,** instead of a `migrate-state` subcommand. That keeps the CLI one flat argparse parser, as today.

## Review Focus

1. **Non-ASCII text through `claude` stdin on Windows** (₹, Hindi names, emoji). Expect a UTF-8 round trip with no `UnicodeEncodeError` or mojibake. Pinned in Task 6 by `test_prompt_sent_as_utf8`.
2. **`claude` hangs**, for example when not logged in or waiting on an interactive prompt. Expect stdin to be closed after writing, a per-call timeout, then fallback. Pinned in Task 6 by `test_timeout_raises_timeout_kind` and Task 7 by `test_timeout_falls_back_but_claude_retried_next_call`.
3. **Model wraps the JSON in prose or ```json fences.** Expect the first JSON object to be extracted, not a hard failure. Pinned in Task 6 by `test_parse_result_with_code_fence`.
4. **Ctrl+C or a crash mid-stage** (say during render). Expect the stage not to be marked done, and the next `main.py` to rerun only that stage. Pinned in Task 15 by `test_failed_stage_not_marked_done_and_resumes`.
5. **`--approve-packaging` with no waiting run, or with an out-of-range `--variant`.** Expect a clear error, exit code 2, and no file changed. Pinned in Task 18 by `test_approve_without_run_exits_2` and `test_approve_bad_variant_exits_2`.

### Task 7: LLM router (fallback, retry, breaker)

**Files:**
- Create: `yt_video/providers/llm/router.py`, `tests/providers/test_router.py`

**Interfaces:**
- Consumes: `LLMProvider`, `CostLedger.record`, `LLMResult`, `LLMError`.
- Produces:
  - `LLMRouter(providers: list[LLMProvider], ledger: CostLedger | None, run_id: str, claude_only: bool = False)`
  - `.complete(req: LLMRequest, stage: str) -> LLMResult`
  - `.disabled: set[str]`
  - `build_router(settings: Settings, ledger: CostLedger | None, run_id: str, claude_only: bool) -> LLMRouter`: builds providers in `settings.llm_providers` order
- Rules (spec §6.3):
  1. Skip a provider when `not available()` or its name is in `disabled`. Record reason `"unavailable"`.
  2. On `ProviderError` move to the next provider. Kind `usage_limit` adds the provider to `disabled` for the rest of the run. `timeout` and `exit` do not.
  3. When `req.schema` is set, validate `data` with `schema.model_validate`. On `ValidationError` retry the **same** provider once, with the prompt suffixed `"\n\nYour previous reply failed validation:\n<errors>\nReturn corrected JSON only."`. A second failure moves on with reason `"invalid_output"`.
  4. When `claude_only`, only providers named `claude_cli` are tried.
  5. Record every successful call to the ledger. `fallback_reason` is the joined reasons of the earlier attempts, or None.
  6. When every provider fails, raise `LLMError(attempts)`. The message lists each `provider: reason`.

## Spike Findings

Measured with `claude` v2.1.332 (OAuth subscription), cwd = empty temp dir, never `--bare`. Fixtures in `tests/fixtures/claude/` (UUIDs and `credential_expires_at` scrubbed; `usage_limit.json` is **synthetic**).

### Recommended argv (Task 6)

```
claude -p --model <haiku|sonnet> --output-format json --tools "" --no-session-persistence \
  --strict-mcp-config --setting-sources "" --system-prompt "<system>" [--json-schema '<schema>']
```

Prompt goes on stdin. `--system-prompt-file <path>` exists and works (verified); prefer it for long system prompts to avoid Windows command-line limits. Only cwd matters beyond this: run in an empty temp dir.

### Envelope (stdout is a single JSON object, exit 0 on success)

- Text: `result` (str). Error flag: `is_error` (bool); also `subtype` ("success"), `terminal_reason` ("completed" | "api_error"), `stop_reason`, `api_error_status` (int or null), `api_error_type` (on errors).
- Structured output (`--json-schema`): separate key `structured_output` (object) AND `result` holds the same JSON as text. Costs an extra turn (`num_turns` 2, `stop_reason` "tool_use") and ~500 more input tokens (schema tool). Prefer `structured_output`, fall back to `json.loads(result)`.
- Usage: `usage.input_tokens`, `usage.cache_creation_input_tokens`, `usage.cache_read_input_tokens`, `usage.output_tokens` (all four needed; `input_tokens` alone is ~2). Per-model: `modelUsage.<model-id>.{inputTokens,outputTokens,cacheReadInputTokens,cacheCreationInputTokens,costUSD}`.
- Cost: `total_cost_usd`. Timing: `duration_ms`, `duration_api_ms`. Also `session_id`, `uuid`, `num_turns`, `permission_denials`.

### Isolation / token overhead (haiku, "Reply with the word ok", total input = input + cache_creation + cache_read)

| Flags | Total input tokens |
|---|---|
| default (user+project+local settings) | 8,454 |
| `--setting-sources project` | 7,117 |
| `--setting-sources local` | 756 (cache hit) |
| `--setting-sources ""` (accepted, no error) | 756 |

`--setting-sources ""` is accepted and cuts overhead ~91%; it still authenticates. Default load showed the global CLAUDE.md in the model's self-report; with `""` it did not, though the model still echoed some generic environment text from the base prompt (the ~750-token residual, accepted per spec 5.1.6). No hook/plugin/superpowers text appeared with `""`. Adding `--json-schema` adds ~500 tokens.

### Models

`--model haiku` -> `claude-haiku-5-5`; `--model sonnet` -> `claude-sonnet-5-5` (aliases resolve; full IDs not needed).

### Failures

- Invalid model: exit **1**, stdout is a normal JSON envelope with `is_error: true`, `api_error_status: 404`, `api_error_type: "not_found_error"`, `terminal_reason: "api_error"`, `result` = "There's an issue with the selected model (...)"; stderr `[claude-code:unrecognized_model] {...}`. Zero cost/usage. See `error.json`.
- Unknown CLI flag: exit 1, plain text on stderr, no JSON.
- So: parse stdout JSON even when returncode != 0; fall back to stderr text if stdout isn't JSON.
- Usage-limit: **not observed**; fixture is synthetic (assumed 429 `rate_limit_error`). Message strings found in the CLI binary: `You've hit your limit`, `You've hit your monthly limit`, `You've hit your fast limit`, `Usage limit reached` (variants with "resets ...", "set to continue automatically"), `Credit balance is too low`, `Extra usage is required for long context`, `Extra Usage`. Detection rule: `is_error` and (`api_error_status` in {429, 402} or case-insensitive match on `hit your .*limit|usage limit reached|credit balance is too low|extra usage|rate_limit|overloaded`) in `result`/stderr. Treat as non-retryable-on-Claude and fall back to the OpenAI provider / trip the breaker. Verify against a real limit when one occurs.

### Latency

Haiku trivial call: ~2.2s. Sonnet with a ~6,000-word prompt (13.5k input tokens, ~130-word answer): `duration_ms` 4.2s, wall ~6s including CLI startup. Single sample with a short answer; long generations (a full script) will be dominated by output speed. The defaults stand: `CLAUDE_TIMEOUT_S` 600 (script) and 180 (light); measured p95 x 2 is far below both, so no increase. Budget ~1 call per few seconds plus output length.
